# Cutover Pecuária

Fonte canônica somente depois de `npm ci`, `npx playwright install chromium`, `npm run check`, `npm run qa:web` e `npm run build:win` verdes, seguida de homologação do instalador e abertura de um banco `artisys-pecuaria.sqlite` existente. Até lá, o monorepo permanece rollback/reference.
